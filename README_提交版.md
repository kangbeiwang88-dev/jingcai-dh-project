# 京彩 - 北京文化生活入口

## 项目说明

本项目是一个面向公众的北京文化生活资源网站，整合了以下功能：

- 文化资源导航（博物馆、图书馆、剧场等）
- 演出展览信息
- 阅读空间推荐
- 文化地图
- 无障碍友好路线
- 人群专属指南

## 快速启动

### 方法一：直接预览（推荐）

1. 双击运行 `启动预览.bat`
2. 等待浏览器自动打开
3. 地址栏显示：`http://127.0.0.1:5310`

### 方法二：命令行启动

```bash
# 1. 安装依赖（如未安装）
npm install

# 2. 启动开发服务器
npm run dev

# 3. 浏览器打开 http://127.0.0.1:5310
```

## 技术栈

- React 19 + TypeScript
- Vite 6
- Tailwind CSS 3
- React Router 7
- Lucide React 图标库
