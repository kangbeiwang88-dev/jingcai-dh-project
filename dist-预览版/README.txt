# 京彩 - 北京文化生活入口（预览版）

## 如何预览

### 方法一：双击启动（推荐）

1. 双击运行 `启动预览.bat`
2. 浏览器会自动打开 http://127.0.0.1:8080
3. 即可浏览网站

### 方法二：Python 服务器

```bash
cd 当前位置
python -m http.server 8080
```
然后浏览器打开 http://127.0.0.1:8080

### 方法三：VS Code Live Server

用 VS Code 打开此文件夹，安装 Live Server 插件，右键 index.html 选择 "Open with Live Server"

## 功能页面

- 首页：文化资源搜索与发现
- 文化资源：图书馆、博物馆、剧场等资源列表
- 演出展览：本周演出与展览信息
- 阅读空间：自习室与阅读场所
- 文化地图：地图浏览资源分布
- 无障碍友好：残障人士出行指南
- 人群指南：按人群推荐文化去处

## 技术说明

本版本为已构建的静态网页，可直接在本地服务器运行。
